特点Features

熟悉的 NekoBox，可靠的 FlClashNekoBox on the outside, FlClash inside

界面照着 NekoBox 重新排布，订阅、规则、覆写、TUN 和分应用代理这些功能全部来自 FlClash，没有改动。 The screens follow NekoBox; profiles, rules, overrides, TUN and per-app proxy all come from FlClash unchanged.

侧滑抽屉Side drawer

粉色顶栏左上角的 ☰ 打开抽屉，取代底部导航栏：代理、配置、仪表盘、请求、连接、DNS、资源、工具一目了然。The ☰ in the pink bar opens a drawer in place of the bottom bar, with proxies, profiles, dashboard, requests, connections, DNS, resources and tools.

代理即主页Proxies first

分组在粉色标签栏里切换，节点是单列卡片，正在使用的节点左侧有一道粉色竖条。Groups switch in a pink tab strip, nodes are one-column cards, and the node in use carries a pink bar.

纸飞机与统计栏Paper plane and stats bar

点纸飞机连接，底部滑出统计栏，实时显示上传与下载速度；点一下统计栏就能测试连接延迟。Tap the paper plane to connect; a stats bar slides up with live speeds and tests the connection when tapped.

NekoBox 粉NekoBox pink

默认主题色就是 NekoBox 的 #FB7299，浅色与深色模式都适配。The default theme color is NekoBox's #FB7299, in both light and dark mode.

与 FlClash 共存Lives beside FlClash

独立包名 com.nekoclash，可以和 FlClash 同时安装，订阅与设置互不影响。Its own package, com.nekoclash, installs beside FlClash with separate profiles and settings.

mihomo 内核mihomo core

沿用 FlClash 的 mihomo（Clash.Meta）内核，目前为 v1.19.33，并移植了上游的关键修复。FlClash's mihomo (Clash.Meta) core, now v1.19.33, with upstream's key fixes picked over.

构建Build

从源码构建Build from source

也可以自己构建。准备好 Flutter 3.47、Go 1.27 以及带 NDK 的 Android SDK，然后运行： You can also build it yourself. With Flutter 3.47, Go 1.27 and the Android SDK with the NDK, run: 

git clone --recursive https://github.com/xikijinise/NekoClash.git
cd NekoClash
flutter pub get
flutter build apk --release \
  --target-platform android-arm64 \
  --dart-define=APP_ENV=stable
  • 安装包在 build/app/outputs/flutter-apk/app-release.apk，Go 内核会一并编译。The APK lands in build/app/outputs/flutter-apk/app-release.apk; the Go core builds with it.
  • 用自己的密钥签名：把 keystore.jks 放进 android/app/，并在 android/local.properties 写入 storePassword、keyAlias、keyPassword。To sign with your own key, put keystore.jks in android/app/ and storePassword, keyAlias and keyPassword in android/local.properties.
  • 不加 APP_ENV=stable 时右上角会显示“PRE”；debug 构建的包名是 com.nekoclash.dev。Without APP_ENV=stable the app shows a "PRE" banner; debug builds use com.nekoclash.dev.

自动化Automation

链接导入与自动化Links and automation

打开下面格式的链接即可导入订阅，clashmeta:// 与 flclash:// 同样可用。 Open a link in this form to import a subscription; clashmeta:// and flclash:// work too. 

clash://install-config?url=<URL-encoded link>

Tasker、MacroDroid 可以用这些 Action 启动、停止或切换代理，电脑上也能用 adb： Tasker or MacroDroid can start, stop or toggle the proxy with these actions, and so can adb: 

com.nekoclash.action.START
com.nekoclash.action.STOP
com.nekoclash.action.TOGGLE

adb shell am start -a com.nekoclash.action.TOGGLE
